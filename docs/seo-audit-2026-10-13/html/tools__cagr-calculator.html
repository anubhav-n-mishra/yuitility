The maths behind the cagr calculator

So you can check the result rather than take it on trust.

The formula

CAGR = (Ending value ÷ Beginning value)^(1 ÷ n) − 1

  • ·n — number of years (fractional years are allowed)

Worked example

₹1,00,000 grows to ₹2,50,000 over 5 years.

Ratio
2,50,000 ÷ 1,00,000 = 2.5
Root
2.5^(1/5) = 1.20112

CAGR = 20.11% per year.

CAGR is the constant rate that would have produced the same endpoints. It deliberately erases the path — an investment that fell 40% in year 2 and an investment that rose steadily can report the identical CAGR. Use it to compare endpoints, never to describe risk.

Where this calculation usually goes wrong

CAGR cannot handle added or withdrawn money

If you invested more part-way through, CAGR between the first and last value is meaningless. That is what IRR (or XIRR) is for.
